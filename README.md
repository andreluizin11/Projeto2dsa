# Clínica do 2°DS-A

Sistema de agendamento médico com banco de dados em nuvem.

## Tecnologias
Next.js (App Router, Server Components e Server Actions), TypeScript, Tailwind CSS, Supabase (PostgreSQL com RLS), GitHub e Vercel.

## Funcionalidades
- Lista as consultas (SELECT com JOIN em pacientes, médicos e consultas)
- Agenda novas consultas por formulário (INSERT)

## Banco de dados
Três tabelas relacionadas: `pacientes`, `medicos` e `consultas` (relações 1:N).
